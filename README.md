# Don't Forget AI 🧠

**Your Everyday Memory Assistant**

Don't Forget AI is a simple web app designed to help users organize daily tasks, reminders, and checklists in one place.

## Features

- 💬 Chat assistant with predefined responses
- ✅ Create and manage tasks
- ⏰ Set dates and times for reminders
- 📋 Create and reuse checklists
- 🔍 Search saved checklists
- 🌙 Dark mode
- 🔔 Browser notifications
- 💾 Save data in browser Local Storage

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start organizing your tasks and checklists.
